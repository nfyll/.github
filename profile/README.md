# NFYLL

**North Florida Youth Lacrosse League** — a 501(c)(3) nonprofit organizing
spring rec lacrosse for youth players across northeast Florida.

- 🌐 [nfyll.org](https://nfyll.org)
- ✉️ [board@nfyll.org](mailto:board@nfyll.org)

## Repos

- [**nfyll**](https://github.com/nfyll/nfyll) — `nfyll.org` website (Astro)
- [**infra**](https://github.com/nfyll/infra) — Bicep IaC for NFYLL Azure resources (private)
- [**.github**](https://github.com/nfyll/.github) — this org profile + reusable workflows
